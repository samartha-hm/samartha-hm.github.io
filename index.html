AUTONOMOUS ARECANUT

  • Team Leadership: Led a 4-person team across mechanical, electronics, firmware, and dashboard layers over a 6-month build cycle.
  • Three-Layer Control Architecture: React/FastAPI/WebSocket dashboard (Frontend) → Raspberry Pi 5 as middleware, auto-detecting hardware ports and applying calibration trims (Backend) → Arduino Mega running a non-blocking finite state machine for real-time PWM generation (Firmware).
  • Robust Binary Protocol: Built a custom 6-byte binary protocol between the two boards, with an XOR-based checksum on every packet to discard corrupted data and prevent erroneous motor commands.
  • Autonomous Coverage: Implemented a dead-reckoning "vertical-serpentine" grid traversal algorithm for autonomous coverage of the drying yard, with ultrasonic obstacle detection and debounced auto-recovery.
  • Isolated Power Architecture: Designed a dual-battery isolated power architecture (separate logic and actuation batteries) to eliminate brownout resets under high motor load — a common failure point in robots drawing both compute and actuation from one supply.
  • Safety & Local Hotspot: Built the control dashboard with a Hold-to-Move safety mechanism that instantly halts the robot if directional input is released, served over a Pi-hosted local Wi-Fi hotspot.
  • Deep Learning Quality Pipeline: Developed and validated (offline) a U-Net + ResNet-50 deep learning pipeline for automated drying-stage classification — U-Net selected for its precise pixel-level segmentation of arecanut from background noise (Dice Coefficient: 0.92); ResNet-50 achieved 96.5% accuracy (unpeeled) and 98.2% (peeled) across 4 drying stages (validated proof-of-concept; future on-device integration planned via the Pi 5's Hailo-8L accelerator).
  • Mechanical Engineering: Fabricated and field-tested a mechanically stable, low-profile 4WD chassis with a centrally mounted roller mechanism.
